What OREBOT is

thesis

An agent, not a mascot

Orebot runs 24/7: it watches wallets across Base and Solana, tracks market data and executes its own trades. The token is the onchain handle for that agent on BNB Chain.

Agent-gated from block one

The launch uses Flap's Agent ID extension. Buying or selling on the curve requires holding a Binance Agent ID, and every origin is capped at 2% of supply.

Tax funds the machine

1% on buys and 1% on sells for the whole tax window. Revenue routes to the project treasury that pays for the agent's data feeds, RPC and execution.

The Agent ID gate

who can trade

Only verified agents trade the curve

The launch is created with Flap's nft_gated.v1 extension pointing at the Binance Agent ID collection. Swaps check the ERC-721 balance of tx.origin: less than one Agent ID and the trade reverts with NFTGatedOnly.

collection 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F

The gate applies to the launch curve only. Once the token graduates to the DEX, anyone can trade it.

Why gate it at all

Snipers and bot swarms are the main reason agent tokens die on day one. A gate plus a 2% per-wallet cap means the early curve is filled by wallets that proved they are agents, not by a fresh address per millisecond.

Note: a buyer below the cap fills up to it and gets the excess refunded in the same transaction. Above the cap, the buy reverts.

How to buy

4 steps
  1. Get a Binance Agent ID

    Open the Binance app, start Binance AI Pro, create an Agentic Wallet and claim a .ai name. The Agent ID NFT lands in that wallet and is your ticket to the curve.

  2. Fund the wallet with BNB

    You need BNB for the buy plus a little gas. Keep it on BNB Smart Chain (chain ID 56).

  3. Buy on Flap

    Open the OREBOT page on Flap and swap BNB for OREBOT. Remember the 2% per-wallet cap on every buy while the token is on the curve.

  4. Verify before you sign

    Check the contract address matches the one on this page, and check that nftGate on the token equals the Agent ID collection. Anything else is not OREBOT.

The Agent ID check reads the wallet that signs the transaction, not the wallet that holds the tokens. Sending OREBOT to a wallet without an Agent ID is fine — that wallet just cannot sell on the curve.
